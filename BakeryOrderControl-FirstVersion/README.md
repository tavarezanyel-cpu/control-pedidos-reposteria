# Bakery Order Control - First Version

C# console application for a bakery that manages products, customers and orders.
It supports adding, searching (by several criteria), editing, deleting and listing records.
Data is kept in memory using lists and a dictionary (it is lost when the program closes).

The program does not close until the user chooses to exit, and invalid input is handled without crashing.

## Run
```
dotnet run
```
